🏦 BANKING ANALYTICS DASHBOARD – POWER BI PROJECT
Project Overview

The Banking Analytics Dashboard is a Power BI-based data analytics project developed to analyze banking customer information and financial performance. This dashboard provides meaningful insights into customer behavior, branch performance, risk analysis, credit score distribution, and account balances.

The project helps banking organizations make data-driven decisions by converting raw banking data into interactive visual reports and dashboards.

The dashboard includes KPI tracking, branch-wise analysis, customer risk categorization, total balance monitoring, and customer credit score evaluation.

Dashboard Features
1. KPI Cards

The dashboard includes key performance indicators such as:

Total Balance
Customer Count
Average Credit Score

These KPIs provide a quick summary of banking performance.

2. Branch-wise Credit Score Analysis

A bar chart is used to compare the average credit score by branch, helping identify customer financial stability across locations.

3. Risk Analysis

A pie chart is implemented to visualize:

High Risk Customers
Low Risk Customers

This helps in identifying customer risk patterns.

4. Total Balance by Branch

A line/area chart is used to analyze the total account balance maintained in different bank branches.

5. Highest Balance by Branch

A funnel chart is used to compare branches based on balance contribution.

6. Interactive Filters (Slicers)

The dashboard contains branch filters for:

Bangalore
Chennai
Hyderabad

This improves interactivity and allows dynamic report analysis.
